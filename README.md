# Palais El Menzeh, démonstration de site

Site vitrine de prospection pour Palais El Menzeh à Meknès. Français, anglais et arabe avec lecture de droite à gauche. Demande de visite par WhatsApp, appel direct, galerie et carte Google intégrée.

## Démarrer

```sh
pnpm install
pnpm dev
```

`pnpm build` génère le site statique dans `dist/`.

## Sources et validation

- Profil Instagram public : https://www.instagram.com/palais_el_menzeh/ . Le numéro 06 61 82 81 07 figure dans le titre et la bio du profil lors de la recherche du 22 octobre 2026.
- Adresse R718 à Meknès et photos du lieu : https://zafaf.ma/vendor/palais-el-menzeh-meknes . Les images du dossier `public/images` sont utilisées pour cette démonstration et proviennent de cette fiche publique. Confirmer l'autorisation d'usage des photographies avec le client avant mise en production.
- La fiche d'annuaire indique des tarifs sur devis. Aucun tarif, capacité, formule ou menu n'a été inventé.
- Les horaires et la disponibilité doivent être confirmés avec le propriétaire. La carte intégrée vise l'établissement indiqué par Google Maps.

Ce site est une démonstration commerciale indépendante, sans représentation officielle de Palais El Menzeh.
